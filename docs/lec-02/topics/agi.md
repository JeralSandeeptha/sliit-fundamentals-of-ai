# AGI (Artificial General Intelligence)

- `Status`: Theoretical / In-development
- `Alias`: Strong AI or Human-Level AI
- `Scope`: Broad intellectual tasks
- `Mechanics`: Commonsense reasoning, abstract thinking, and adaptive learning
- `Key` Trait: Solves unfamiliar problems without pre-training
- `Examples`: A system that can learn medicine, compose music, and fix a car autonomously
