# Tasks in AI

AI tasks can be divide into 3 groups

### Mundane Tasks:

- Perception
- Vision
- Speech
- Natural Languages
  * Understanding
  * Generation
- Translation
- Common sense reasoning
- Robot Control

### Formal Tasks:

- Games: chess, checkers, etc
- Mathematics: Geometry, logic, Proving properties of programs

### Expert Tasks:

- Engineering ( Design, Fault finding, Manufacturing planning)
- Scientific Analysis
- Medical Diagnosis
- Financial Analysis
