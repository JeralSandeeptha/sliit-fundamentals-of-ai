# Russel Norvig Categorization

`The Russell and Norvig Categorization` refers to the foundational framework for Artificial Intelligence (AI) and intelligent agents

<br/>

**Humanly vs. Rationally**: Do we imitate human biology (neurons/emotions) or mathematical logic (utility)?

**Thinking vs. Acting**: Do we focus on internal thought processes or external observable behavior?

---

| | **Human-Centered** | **Rationality-Centered (තාර්කිකත්වය)** |
| :--- | :--- | :--- |
| **Thinking** | **Thinking Humanly**: Cognitive modeling and replicating human thought. | **Thinking Rationally**: Using strict mathematical logic and the "laws of thought." |
| **Acting** | **Acting Humanly**: Performing behaviors that require intelligence when done by humans (e.g., passing the Turing Test). | **Acting Rationally**: Operating as an intelligent agent to maximize expected utility or goals. |

<br/>

**Thinking Humanly (Cognitive Science)**: This approach seeks to understand how the human mind works and replicate those exact internal cognitive processes within software (e.g., neural networks mimicking biological brains).

**Thinking Rationally (Laws of Thought)**: Rooted in formal logic, this approach relies on structural patterns (like syllogisms or expert rule systems) to deduce undeniably correct statements from given premises.

**Acting Humanly (The Turing Test Approach)**: This view focuses purely on outward execution. If a computer's behavior is indistinguishable from a human's to an external observer, it is considered intelligent.

**Acting Rationally (The Intelligent Agent Approach)**: This is the primary focus of the Russell & Norvig textbook. It defines AI as creating rational agents that perceive their environment and take the best possible actions to achieve their intended goals, regardless of whether those actions perfectly match human behavior.
